# Konstanta CZ — сайт агенції з працевлаштування в Чехії

Статичний сайт: `index.html`, `styles.css`, `script.js`. Нічого збирати не потрібно — достатньо відкрити `index.html` у браузері.

## Як редагувати
- **Тексти та розділи** — `index.html`
- **Кольори, шрифти, відступи** — `styles.css` (основні кольори на початку файлу, у блоці `:root`)
- **Вакансії** — масив `JOBS` на початку `script.js`
- **Анімація «Шлях кандидата»** — блок `ШЛЯХ КАНДИДАТА` у `script.js` та `styles.css`

Після зміни `styles.css` або `script.js` збільште номер версії в `index.html` (`styles.css?v=3` → `?v=4`), щоб браузери відвідувачів підтягнули нову версію.
